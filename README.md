# arium-landing

This repository contains the static landing page for **Arium Immigration**. The site is deployed via GitHub Pages from the `docs` folder.

## Repository layout

- **docs/** – HTML, images, and the `CNAME` file used for deployment
- **scraper/** – Data and a Jupyter notebook used to collect immigration adviser information

To run the site locally, simply open `docs/index.html` in a browser. All assets are self-contained.
