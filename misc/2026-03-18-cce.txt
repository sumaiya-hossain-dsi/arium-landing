  ---
  Viewing locally

  Yes, very easy. Since it's pure static HTML/CSS/JS, you have two options:

  Option 1 — Python (simplest, no install needed on most Windows)

  Open a terminal in the repo root and run:
  python -m http.server 8080 --directory docs
  Then open http://localhost:8080 in your browser. Works perfectly.

  If python doesn't work, try python3.

  Option 2 — Just open the file directly

  Open docs/index.html in your browser (double-click it in File Explorer, or
  drag it into a browser tab). This works for ~95% of things. The only caveat:
  Google Fonts may not load over file:// on some browsers — you'd see the
  fallback font instead of Inter. The layout, content, dark mode, nav,
  everything else works fine.

  Option 3 — VS Code Live Server

  If you have VS Code, right-click docs/index.html → Open with Live Server.
  Auto-reloads on save, serves on http://localhost:5500.

  ---
  I'd recommend Option 1 or 3 for the most accurate preview (fonts will load).
  Once you've checked it out, let me know what needs adjusting!
